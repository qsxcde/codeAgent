## Why

当前 TUI 能显示基本的对话、工具调用和上下文用量，但运行状态仍主要依赖一个 running 布尔值和“思考中”动画；长时间模型请求、工具执行、取消、超时、恢复和压缩过程缺少明确反馈。与此同时，流式输出会反复解析完整正文并重渲染全部历史，工具大输出展开后也没有分页，导致大型会话中输入延迟、滚动跳动甚至界面卡顿。

现在需要把 TUI 从“能工作”的开发者 MVP 提升为可观测、可恢复、能承受大输出的日常使用界面。

## What Changes

- 引入明确的 TUI 运行阶段：空闲、等待模型、流式输出、工具排队/执行、等待确认、压缩、取消、失败和恢复。
- 扩展事件生命周期和运行元数据，使 TUI 可以显示当前阶段、耗时、工具状态、超时/清理不确定性和可重试性。
- 重做底部状态栏和 /status 详情：显示阶段摘要、耗时、当前操作、错误诊断，并保留上下文占用与模型信息。
- 为流式正文和历史消息增加渲染节流、块级缓存、可视区渲染、滚动跟随提示和 resize 防抖，避免每个增量都全量重绘。
- 为工具结果增加输出统计、截断标记、首尾预览和分页/导出入口，避免展开几十万字符时阻塞 TUI。
- 大型会话恢复和上下文压缩显示明确的加载状态；退出时分块输出完整文档，避免一次性构造全部行。
- 定义安全的失败后重试/继续语义，避免重复执行已经产生副作用的工具调用。
- 增加运行状态、渲染性能、大输出分页、会话恢复和退出完整性的离线测试与基准测试。

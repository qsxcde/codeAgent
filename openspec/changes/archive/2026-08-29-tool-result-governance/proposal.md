## Why

当前工具结果虽然已有字节/行截断、退出码字段和 TUI 分页，但这些能力分散在具体工具、core 归一化、事件映射和展示层之间。结果统计与截断事实会在适配、模型消息或会话恢复时丢失，大结果还可能先被完整读入内存，导致模型无法判断结果是否完整、TUI 无法可靠展示范围，也无法基于下一次请求预算稳定控制上下文膨胀。

## What Changes

- 建立统一的工具结果治理契约，将执行状态、语义成功、输出完整性、总量、展示量、截断原因、路径、退出码、耗时和变更摘要作为结构化事实传递。
- 在工具结果进入模型上下文前执行两级限制：工具级硬上限保护内存与输出规模，请求级预算上限根据下一次模型请求的剩余预算进一步裁剪或生成确定性摘要。
- 统一 bash、read、grep、find、ls、MCP 和 skill 的结果策略；保留工具特有的头部/尾部、继续读取参数、stderr、退出码和文件变更摘要语义。
- 修复 `AgentToolAdapter`、core 结果归一化、工具事件和 tool message 的元数据丢失，使模型视图、事件视图和会话恢复视图使用同一份权威事实。
- 为会话 JSONL 增加向后兼容的工具输出元数据存储；不把未受控的完整原始输出写入会话文件，无法恢复的截断结果必须明确标记。
- 让 TUI 根据结构化元数据渲染摘要、范围、分页和截断诊断；文本标记解析仅作为旧会话/旧适配器的兼容回退。
- 增加大结果、预算不足、非文本 MCP 内容、恢复、并发工具结果和敏感输出边界的离线回归测试。

## Capabilities

### New Capabilities

<!-- 本变更扩展现有工具结果、上下文、会话和 TUI 能力，不新增独立能力域。 -->

### Modified Capabilities

- `tools`: 增加统一工具结果治理、硬限制与工具特定输出策略。
- `core`: 增加工具结果结构化事实在执行、事件和模型消息之间的传递契约。
- `context-budget`: 增加工具结果按下一次模型请求预算受控裁剪的契约。
- `sessions`: 增加工具结果元数据的向后兼容持久化和恢复契约。
- `tui`: 将大输出预览、分页和导出切换为结构化结果元数据驱动。

## Impact

- 影响 `src/codeagent/tools/shared/`、各原子工具、MCP 适配器和进程输出采集。
- 影响 `src/codeagent/core/contracts/`、工具执行归一化、ReAct turn 消息构造和生命周期事件映射。
- 影响 `src/codeagent/session/persistence/` 的消息编码/解码及恢复投影，但保持旧 JSONL 文件可读取。
- 影响 `src/codeagent/app/tui/` 的工具结果块、输出缓冲和 `/output` 命令。
- 不新增依赖；不改变工具名称、输入参数、安全确认语义、工具调用顺序或既有模型 provider 接口。
- 默认不保存完整原始工具输出；若工具层已经丢弃超限内容，调用方只能看到有界结果和明确的不可恢复诊断。

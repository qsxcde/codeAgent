## 1. 迭代概述

### 1.1 迭代目标

在 v0.2「好用」(会话可恢复/可切换/可压缩/可分叉 + 安全 + TUI 完整)之上推进**生态成型**(F-18~F-24,§12.3 v0.3 验收):

1. **扩展生态**:Skills 按需加载(F-18)、MCP 外部工具接入(F-20)——对标 Claude/Codex Skills;插件系统(F-19)经评估移出本迭代(见 E5,能力已被技能 + MCP 覆盖);
2. **体验差异**:成本透明(F-22)——信任赤字对冲(需求分析 §10.2:成本透明是社区高赞、与事件流天然契合的差异化);轻量记忆(F-21)经评估移出本迭代(见 E4);
3. **平台与导航**:会话树 UI(F-23 剩余,分支 fork 已在 v0.2 提前落地);Web/HTTP 事件流订阅(F-27)经评估移出本迭代(见 E12——价值已被 CLI/TUI 事件流订阅覆盖,平台向无真实消费者)。

对标 Pi(earendil-works/pi)的 resource-loader / skills 体系(2026-08-15 源码实查 AGENTS.md 与 compaction,2026-08-19 实查 skills.ts);**注意:Pi 无插件系统**(仓库不存在 extensions/loader.ts,此前"对齐 Pi extensions"引用失效,见 E5)。

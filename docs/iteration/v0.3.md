## 1. 迭代概述

### 1.1 迭代目标

在 v0.2「好用」(会话可恢复/可切换/可压缩/可分叉 + 安全 + TUI 完整)之上推进**生态成型**(F-18~F-24,§12.3 v0.3 验收):

1. **扩展生态**:Skills 按需加载(F-18)、插件系统(F-19)、MCP 外部工具接入(F-20)——对标 Claude/Codex Skills 与本地插件;
2. **体验差异**:轻量记忆(F-21)、成本透明(F-22)——信任赤字对冲(需求分析 §10.2:成本透明是社区高赞、与事件流天然契合的差异化);
3. **平台与导航**:会话树 UI(F-23 剩余,分支 fork 已在 v0.2 提前落地)、Web/HTTP 事件流订阅(F-27,承接 v0.2 对 F-24 平台部署的改写决策)。

对标 Pi(earendil-works/pi)的 resource-loader / skills / extensions 体系(2026-08-15 已源码实查 AGENTS.md 与 compaction,本轮继续对照其 skills.ts / extensions/loader.ts / package-manager.ts)。

### 1.2 迭代范围

| 模块 | 范围 |
|---|---|
| `resources/skills/` | SKILL.md 技能格式 + 按需加载 + 渐进式披露(名称/描述进 system prompt,正文经 read 可见) |
| `extensions/` | 插件两阶段(注册→绑定)+ 运行时 + 插件 API(注册工具/命令) |
| MCP | 客户端适配(协议最小面:tools/list → 工具接入)+ 工具数分组预算 |
| 记忆 | `~/.codeagent/memory` 轻量记忆(跨会话偏好/事实)+ 读写工具/注入 |
| 成本 | usage 落库(DR-6)+ 费用估算(单价表)+ 展示(状态栏/事件流/CLI) |
| 会话树 | fork 链数据视图 + TUI `/tree` 导航(`/sessions` 父子展示增强) |
| Web | HTTP 服务 + 事件流订阅(SSE)+ 会话接入(create/run/subscribe) |
| `ai/` | `ModelSpec` 增价格元数据(仿 Pi Model);usage 归一与估算 |
| `tests/` | 全新增量离线测试(mock MCP server / 临时目录树 / FakeClient / 桩服务) |

### 1.3 非目标(明确移出本迭代)

| 项 | 去向 |
|---|---|
| 多智能体协作(F-25) | 远期(事件流天然适配,原型另行规划) |
| Automations 定时任务(F-26) | 远期 |
| 平台部署 `langgraph.json`(F-24) | **随 v0.2 编排自研永久调整**:已改写为 HTTP/事件订阅入口(并入本迭代 F-27) |
| 完整 MCP 生态(采样/溯源/权限模型) | 迭代内做最小协议面;扩展留后续 |
| 记忆的高级形态(向量检索/自动提炼) | 迭代内做键值/文件事实;语义检索远期 |

### 1.4 完成定义(DoD)

1. **Skills**:`resources/skills/` 目录与 SKILL.md 格式定义;按需加载 + 渐进式披露(描述入 system prompt,正文经 read 可见);加载结果可见可断言;
2. **插件**:两阶段注册→绑定可用;插件可注册工具与命令;生命周期(加载/启用/禁用)可离线测试;
3. **MCP**:客户端接入外部工具(工具 schema 转换);工具数分组预算策略生效(控制提示词膨胀);
4. **轻量记忆**:跨会话偏好/事实读写;注入或工具化后模型可用;重启后保持;
5. **成本透明**:usage 落库(DR-6);费用估算(单价表 + 输出/输入/推理 token);可见位置(状态栏/事件流/CLI)至少一处落地;
6. **会话树 UI**:fork 链可导航(`/tree` 或 `/sessions` 父子展示);切换沿用订阅跟随;
7. **Web/HTTP**:事件流订阅(SSE)可消费;会话 create/run/subscribe 至少一闭环;
8. **全量测试离线全绿**:`uv run pytest` 全量通过(基线 512/512),零网络、零密钥(MCP/HTTP 均注入 mock/桩)。

## 5. 当前遗留与后续安排

### 5.1 v0.2 移入项(本迭代落地)

- **F-23 会话树 UI**:分支 fork 已随 v0.2 T-42 提前落地(`session-fork`),本迭代只做剩余导航部分;
- **F-24 平台部署改写**:v0.2 §1.3 定案——`langgraph.json` 平台部署永久调整,改写为 HTTP/事件订阅入口,并入本迭代 F-27。

### 5.2 本迭代已知风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| MCP 协议面过大 | 迭代周期拉长 | 最小面(tools/list、tools/call)+ 分组预算;扩展留后续 |
| 插件安全边界(恶意插件) | 越权访问 | 插件经注入端口交互(不直接跨层 import);边界随安全体系复用 |
| 成本估算与真实计费偏差 | 信任赤字 | 标注"估算";单价表可配置(models.json 覆盖) |
| 记忆内容陈旧/冲突 | 模型误信 | 记忆条目带时间戳;读侧展示来源 |
| Skills/插件注入膨胀提示词 | 上下文成本上升 | 渐进式披露(仅描述入 prompt);MCP 分组预算同思路 |

### 5.3 后续安排(远期)

多智能体协作(F-25)、Automations 定时任务(F-26)、Web 深化与多端(F-27 剩余)、Windows 全平台验证(F-28 已闭环,保持)。

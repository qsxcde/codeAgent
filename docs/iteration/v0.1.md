## 1. 迭代概述

### 1.1 迭代目标

打通 **最小可跑闭环**:CLI/TUI 可对话、可调用 `read / write / edit / bash` 工具、事件流可订阅。

### 1.2 迭代范围

| 模块 | 范围 |
|---|---|
| `config` | 全局 Settings(仅 provider 无关字段) |
| `ai/` | 多 provider 模型配置层 + 统一创建入口 + 模型目录 + 离线 fake |
| `tools/` | 原子工具(read/write/edit/bash)+ 注册表 + Windows bash 适配 + 危险命令黑名单 |
| `core/` | 编排层:端口 / 状态 / 图 / 节点 / 事件(全异步 ReAct) |
| `session/` | 事件总线 + 有状态会话(session + bus) |
| 组合根 | container 接线(工具/模型唯一交汇行) |
| 入口 | headless CLI(`--prompt` / stdin 双路径)+ TUI |
| 测试 | 镜像分包 + FakeClient 离线全测 + 解耦扫描 |

### 1.3 非目标(明确移出本迭代)

| 项 | 去向 |
|---|---|
| 会话持久化(SessionStore)/ SessionManager / 上下文压缩 | v0.2 |
| 敏感操作确认环 / 文件访问边界白名单 | v0.2(黑名单先行兜底) |
| skills / 插件 / MCP / 记忆 / 成本透明 | v0.3 |
| 会话分叉 fork / 多智能体协作 / 平台部署落地 | v0.3 及远期 |
| 编排引擎自研(自研蓝图第二步) | 暂缓,蓝图存档 |

### 1.4 完成定义(DoD)

1. 无任何 API Key 时,以 `fake` provider 可完整跑通"对话 → 工具调用 → 事件流"闭环;
2. 全量测试离线(零网络、零密钥)通过;
3. 解耦判据成立:`core/` 不含 `config / tools / ai / session` 字面量;跨层 import 仅出现在组合根/入口;
4. 危险命令(如 `rm -rf /`)被拦截且拒绝原因可审计;
5. bash 工具在 Windows 开发机(Git for Windows / WSL 探测链)可用。

## 5. 当前遗留与后续安排

### 5.1 测试环境敏感失败(关联 T-11)—— 已闭环 ✅

原问题:`uv run pytest` 实测 **204 项:200 通过 + 4 失败**,均位于 [tests/tools/test_tools.py](../../tests/tools/test_tools.py):

| 失败项 | 现象 | 根因 |
|---|---|---|
| bash cwd 参数 ×3 | 断言期望 Windows 路径 `C:\...\Temp\...`,实际 Git Bash 输出 `/tmp/...` | pytest `tmp_path` 恒在 `%TEMP%`,MSYS 挂载表将其显示为 POSIX 路径;断言与平台路径表示耦合 |
| 管道末段 grep 退出码 ×1 | `; exit ${PIPESTATUS[1]}` 末段首 token 为 `exit` | 测试命令与 P2-13 收窄后的豁免语义(仅 grep 前缀)不符,任何平台都会失败 |

**处理**:OpenSpec change `fix-bash-test-assertions`(2026-08-13):
- 3 项 cwd 断言改为**标记文件法**(预写 `marker.txt`,命令 `test -f marker.txt && echo CWD_OK`),验证"命令在配置的 cwd 中执行"这一真实需求,与平台路径解耦;
- 1 项 PIPESTATUS 测试命令精简为裸管道 `ps aux | grep codeagent-zzz-nonexistent`,追加 `"退出码: 1"` 断言锁定豁免路径。

**结果**:`uv run pytest` **204/204 全绿**,产品代码零改动,测试语义验证强度不降反升。

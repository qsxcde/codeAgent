## 1. 迭代概述

### 1.1 迭代目标

在 v0.1"最小可跑闭环"之上推进两件事:

1. **编排自研(路线 2,大变更)**:按演进蓝图第二步,自研 ReAct 主循环与消息归约,替换 langgraph 编排层(`core/` + `session/` 部分);会话持久化采用 JSONL 树形(对齐 Pi),与运行时状态合一——三个蓝图未决问题已于 2026-08-14 评估:**平台部署非刚需(可放弃 langgraph 生态)、归约 spike 为正确性 gate、JSONL 树形为格式结论**。对应 OpenSpec change `self-built-orchestration`(2026-08-14 落地并归档,主 specs `core` / `sessions` 已同步建立)。
2. **会话层增强**:在自研地基上做会话可恢复 / 可切换 / 可压缩,敏感操作确认环,TUI 命令体系与内容渲染,解耦自动校验(已落地)。

对标 Claude Code / Codex 的行业公约(`/undo`、AGENTS.md、确认环)。

### 1.4 完成定义(DoD)

1. **编排自研落地**:自研 ReAct 主循环 + 消息归约替换 langgraph 编排;pyproject 移除 langchain-core / langgraph,`uv run pytest` 全绿;
2. **事件契约不变**:自研循环产出的事件序列与 v0.1 的 10 类 AgentEvent 逐事件一致(TUI / CLI / 测试无感知);
3. **会话持久化**:JSONL 树形会话文件;重启进程后会话可列出、可恢复继续对话;格式含 `parentId` / `parentSession` 与 `compaction` entry 预留;
4. **SessionManager**:create / switch / dispose;订阅方(TUI/CLI)对切换无感;
5. **上下文压缩**:手动 + 阈值触发;压缩后对话语义不丢失(回归测试);
6. **安全权限**:bash / write 敏感操作默认确认,未确认不执行;read/write/edit 默认限定工作区,越界访问需显式确认;
7. **会话分叉 `/fork`**:从指定消息分叉新会话(Pi `createBranchedSession` 语义);原会话保留、文件保持当前状态;
8. **AGENTS.md**:全局→项目→子目录分层加载并注入系统提示词,越近优先级越高;
9. **TUI 增强**:斜杠命令 / 模糊补全 / 选择器 / `//` 转义、Markdown 正文渲染、滚轮与 PageUp/PageDown 滚动交互落地;
10. **解耦扫描测试**恢复并通过(已完成,T-29);
11. **全量测试离线全绿**:`uv run pytest` 全量通过,零网络、零密钥。

### 5.2 本迭代已知风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 消息归约写错(T-30 gate) | 工具链断裂,模型看不到工具结果 | spike 先行,三场景覆盖;既有 test_loop 断言平移 |

| 测试重写量大(~1,700 行) | 迭代周期拉长 | 断言从"图输出"改"事件序列"为机械转换,先行清单化 |
| compaction 语义丢失 | 压缩不当丢上下文 | 压缩策略可注入 + 压缩前后行为回归测试 |
| 确认环打断自动流程 | 交互繁琐 | 对标 Claude Code 手动挡:仅敏感操作确认,结果可审计 |
| 分叉后文件状态与分支历史不一致 | 被撤销轮次写的文件仍在磁盘 | 分叉时明确提示「文件保持当前状态」,文件回滚不在本迭代(用户可自行 git 处理) |
| 滚动与输入框键位冲突 | PageUp/PageDown 被 TextArea 吞掉 | 输入框聚焦时按键归属显式分派 |
| 平台部署入口永久失效 | langgraph 生态不可用 | 已评估为非刚需;F-24 改写为 HTTP/事件订阅(并入 F-27) |

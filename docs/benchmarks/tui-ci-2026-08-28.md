# TUI CI 性能观测（2026-08-28）

本文记录 GitHub CI 在 Linux runner 上产生的 TUI 性能 artifact。数据用于建立可重复的 CI 观测基线，不代表跨机器的绝对性能承诺。

- Commit: `58051b62ae0a799cf8d72274ca3f0ab57eff476b`
- Python: `3.12.14`
- Platform: `Linux-6.17.0-1022-azure-x86_64-with-glibc2.39`

- 参数：`100` history blocks、`10000` stream chars、`20000` tool-output bytes

## 当前判定

本轮运行时仓库尚未提供与 CI 环境和参数匹配的 `docs/benchmarks/tui-baseline.json`，所以 artifact 中的比较结果为 `no-baseline`。该报告保留为基线建立前的历史观测；当前正式基线已经根据同一轮 Linux CI artifact 固化到 [`tui-baseline.json`](tui-baseline.json)。

现有 `tui-baseline-2026-08-26.md` 来自 macOS，且 history/restore 使用不同规模，不作为当前 CI 比较输入。当前比较固定使用 Linux、Python 3.12、80x24 和四个场景；性能暂只告警，不阻断普通 PR。

# TUI CI 性能观测（2026-08-28）

本文记录 GitHub CI 在 Linux runner 上产生的 TUI 性能 artifact。数据用于建立可重复的 CI 观测基线，不代表跨机器的绝对性能承诺。

## 运行环境

- Commit: `58051b62ae0a799cf8d72274ca3f0ab57eff476b`
- Python: `3.12.14`
- Platform: `Linux-6.17.0-1022-azure-x86_64-with-glibc2.39`
- Viewport: `80 x 24`
- Iterations: `3`
- 参数：`100` history blocks、`10000` stream chars、`20000` tool-output bytes

## 当前判定

本轮比较结果为 `no-baseline`，原因是仓库尚未提供与 CI 环境和参数匹配的 `docs/benchmarks/tui-baseline.json`。因此本报告只能作为观测数据，不能判定性能回归或通过性能阈值。

现有 `tui-baseline-2026-08-26.md` 来自 macOS，且 history/restore 使用不同规模，不可直接作为本报告的比较输入。后续应在同一 Linux CI 环境连续收集稳定数据，再生成 JSON 基线并评估相对阈值。
